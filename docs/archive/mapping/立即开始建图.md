## 🕹️ 现在请操作机器人

### 在**键盘控制节点的终端**使用以下按键：

#### 基本操作：
- **I** - 前进（按几次走几步）
- **J** - 左转（原地旋转）
- **L** - 右转（原地旋转）
- **K** - 停止（紧急制动）
- **,** - 后退

#### 推荐路线（5-8 分钟）：

**第 1 步**（2 分钟）：沿墙壁走一圈
```
1. 按 I 前进，沿着 RMUL2026 的墙壁移动
2. 到角落时按 J 或 L 转向
3. 绕场一周
```

**第 2 步**（2 分钟）：覆盖中间区域
```
1. 走"之"字形路线
2. 确保走遍所有通道
3. 经常小角度转向
```

**第 3 步**（1 分钟）：回到起点
```
1. 返回起始位置附近
2. 长按 J 或 L 原地旋转 360°
3. 触发回环检测
```

## 💾 建图完成后保存

当探索完整个场地后（Rviz 中绿色区域 > 90%），执行以下步骤：

### 步骤 1：结束轨迹

**新打开一个终端**，执行：

```bash
ros2 service call /finish_trajectory \
  cartographer_ros_msgs/srv/FinishTrajectory \
  "{trajectory_id: 0}"
```

看到 `Success: true` 表示成功。

---

### 步骤 2：保存.pbstream 文件

继续在同一终端执行：

```bash
ros2 service call /write_state \
  cartographer_ros_msgs/srv/WriteState \
  "{filename: '/home/weicheng/HzMi_rmsimulation/src/rm_nav_bringup/map/RMUL2026.pbstream', include_unfinished_submaps: false}"
```

看到 `Success: true` 和文件路径表示成功。

---

### 步骤 3：验证结果

```bash
ls -lh /home/weicheng/HzMi_rmsimulation/src/rm_nav_bringup/map/RMUL2026.pbstream
```

**预期输出示例**：
```
-rw-r--r-- 1 weicheng weicheng 3.2M 3 月 21 17:40 RMUL2026.pbstream
```

文件大小通常在 **1-10 MB** 之间。
