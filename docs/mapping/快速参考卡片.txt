┌──────────────────────────────────────────────────────────────────┐
│ ❓ 快速故障排除                                                    │
└──────────────────────────────────────────────────────────────────┘

编译失败？
  → 确保已安装 ROS2 Humble
  → 运行：source /opt/ros/humble/setup.bash
  → 重新运行：./setup_from_package.sh

Gazebo 黑屏？
  → 更新显卡驱动
  → 或运行：export LIBGL_ALWAYS_SOFTWARE=1

LIO 漂移？
  → 检查外参配置
  → 降低运动速度
  → 确认初始位置在地图内

导航不动？
  → 检查 /cmd_vel 话题
  → 调整 robot_radius
  → 查看 costmap 是否有障碍
