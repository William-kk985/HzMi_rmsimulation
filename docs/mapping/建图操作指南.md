### 步骤 5：控制机器人建图 🤖

#### 键位说明：

| 按键 | 功能 | 说明 |
|------|------|------|
| **I** | 前进 | 慢速前进（推荐） |
| **,** | 后退 | 倒车调整 |
| **J** | 左转 | 逆时针旋转 |
| **L** | 右转 | 顺时针旋转 |
| **K** | 停止 | 紧急停止 |
| **U** | 左前斜行 | 全向移动（需配合 Shift） |
| **O** | 右前斜行 | 全向移动（需配合 Shift） |
| **M** | 左后斜行 | 全向移动（需配合 Shift） |
| **.** | 右后斜行 | 全向移动（需配合 Shift） |

#### 建图技巧：

**📍 第一阶段：探索边缘（2-3 分钟）**
1. 按 `I` 键缓慢前进
2. 沿着墙壁走一圈
3. 在每个角落稍作停留并旋转（按 `J` 或 `L`）

**📍 第二阶段：覆盖中间区域（2-3 分钟）**
1. 走 "之" 字形路线
2. 确保覆盖所有通道
3. 避开障碍物

**📍 第三阶段：触发回环检测（1-2 分钟）**
1. 回到起点位置
2. 原地旋转 360°（长按 `J` 或 `L`）
3. 重复经过已探索区域

## 🎯 建图要点总结

### ✅ 应该做的：

1. **慢速稳定** - 速度控制在 0.3-0.5 m/s
   ```bash
   # 如果太快，按 Ctrl 减速
   # 如果太慢，按 Shift 加速
   ```

2. **多旋转** - 在关键位置原地旋转 360°
   - 帮助 Cartographer 识别环境特征
   - 提高定位精度

3. **走闭合回路** - 最终回到起点
   - 触发回环检测（Loop Closure）
   - 消除累积误差

4. **覆盖全面** - 确保所有区域都被扫描到
   - 墙壁边缘
   - 通道走廊
   - 角落和障碍物周围

### ❌ 避免的：

1. **快速转向** - 会导致匹配失败
2. **长时间直线** - 缺少特征点
3. **遗漏区域** - 超过 30% 未探索
4. **碰撞墙壁** - 会影响 IMU 数据

## 📊 观察建图质量

### 方法 1：查看 Cartographer 日志

在 Cartographer 运行的终端观察：

```bash

[INFO] ... Added node ... to trajectory 0
[INFO] ... Localizing trajectory ...
[INFO] ... Found constraint ...

# 警告标志：

[WARN] ... Too few points ...
```

### 方法 2：使用 Rviz 可视化（可选）

```bash
# 新终端

```

在 Rviz 中添加：
- **Map** 显示（话题：/map）
- **LaserScan** 显示（话题：/scan）
- **TF** 显示

**观察要点**：
- 激光束是否与地图边缘对齐
- 绿色区域（已探索）是否覆盖全场
- 灰色区域（未知）是否逐渐减少

### 方法 3：检查话题数据

```bash
# 查看子图列表
ros2 topic echo /submap_list

# 查看轨迹信息
ros2 topic echo /trajectory_node_list

# 查看里程计
ros2 topic echo /odom
```

## 💾 保存.pbstream 文件

当建图完成后（地图完整度 > 90%）：

### 1️⃣ 结束轨迹

```bash
ros2 service call /finish_trajectory \
  cartographer_ros_msgs/srv/FinishTrajectory \
  "{trajectory_id: 0}"
```

**预期输出**：
```
Success: true
Status: Trajectory 0 finished.
```

### 2️⃣ 写入.pbstream 文件

```bash
ros2 service call /write_state \
  cartographer_ros_msgs/srv/WriteState \
  "{filename: '/home/weicheng/HzMi_rmsimulation/src/rm_nav_bringup/map/RMUL2026.pbstream', include_unfinished_submaps: false}"
```

**预期输出**：
```
Success: true
Status: State written to /home/weicheng/HzMi_rmsimulation/src/rm_nav_bringup/map/RMUL2026.pbstream
```

### 3️⃣ 验证结果

```bash
ls -lh src/rm_nav_bringup/map/RMUL2026.pbstream
```

**预期**：文件大小约 1-10 MB

## 🔧 故障排除

### 问题 1：Cartographer 启动失败

**症状**：报错找不到话题或坐标系

**解决**：
```bash
# 检查点云话题
ros2 topic list | grep point_cloud

# 如果没有，检查传感器驱动
ros2 launch livox_driver mid360.launch.py
```

### 问题 2：机器人无法移动

**症状**：按键盘但机器人不动

**解决**：
```bash
# 检查速度话题
ros2 topic echo /cmd_vel

# 如果没有输出，重启键盘控制节点
pkill teleop_twist_keyboard
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```

### 问题 3：建图漂移严重

**原因**：运动过快或 IMU 数据异常

**解决**：
1. 降低移动速度
2. 检查 IMU：`ros2 topic echo /imu/data`
3. 增加旋转动作

### 问题 4：地图不完整

**原因**：有些区域没走到

**解决**：
1. 继续控制机器人探索未覆盖区域
2. 在 Rviz 中观察灰色（未知）区域
3. 针对性地探索这些区域
