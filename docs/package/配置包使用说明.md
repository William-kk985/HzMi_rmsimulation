## 🎯 实际使用场景

### 场景 1：你要发送给其他同学

1. **运行打包脚本**
   ```bash
   cd ~/HzMi_rmsimulation
   ./create_config_package.sh
   ```

2. **发送压缩包**
   - 将生成的 `.tar.gz` 文件通过 QQ/微信/U 盘发送

3. **附带说明**
   ```
   【HzMi_rmsimulation 配置包 v1.0.0】
   
   使用方法：
   1. 解压到任意目录
   2. 运行 ./setup_from_package.sh
   3. 等待编译完成
   4. source install/setup.bash
   5. ./start_sentinel.sh
   
   详细文档见压缩包内的 README_PACKAGE.md
   ```

### 场景 2：同学收到压缩包后

1. **解压**
   ```bash
   tar -xzvf HzMi_rmsimulation_config_package_*.tar.gz
   cd HzMi_rmsimulation
   ```

2. **阅读文档**
   - 先看 `README_PACKAGE.md` 了解概况
   - 再看 `QUICK_START.md` 快速上手
   - 遇到问题查 `HZMI_RMSIMULATION_CONFIG_GUIDE.md`

3. **运行配置**
   ```bash
   chmod +x setup_from_package.sh
   ./setup_from_package.sh
   ```

4. **开始使用**
   ```bash
   source install/setup.bash
   ./start_sentinel.sh
   ```
