# 📤 如何分发 HzMi_rmsimulation 配置包

本指南说明如何将项目打包成压缩包分发给其他同学，无需使用 Git/Gitee。

---

## 🎯 方法一：使用自动化脚本（推荐）

### 步骤 1：创建配置包

在项目根目录运行：

```bash
cd ~/HzMi_rmsimulation
./create_config_package.sh
```

脚本会自动：
- ✅ 复制所有必要的源文件
- ✅ 包含配置文档和使用指南
- ✅ 生成 tar.gz 和 zip 两种格式
- ✅ 清理临时文件

**输出位置：**
```
/home/weicheng/HzMi_rmsimulation/HzMi_rmsimulation_config_package_YYYYMMDD_HHMMSS/
├── HzMi_rmsimulation_config_package_YYYYMMDD_HHMMSS.tar.gz
└── HzMi_rmsimulation_config_package_YYYYMMDD_HHMMSS.zip (如果安装了 zip)
```

### 步骤 2：发送压缩包

将生成的压缩包发送给同学即可。

---

## 🎯 方法二：手动打包

### 步骤 1：整理需要分发的文件

需要包含以下文件/文件夹：

```
HzMi_rmsimulation/
├── src/                          # 必须！所有源码
├── start_sentinel.sh             # 启动脚本
├── save_pcd.sh                   # 保存地图脚本
├── save_grid_map.sh              # 保存地图脚本
├── setup_from_package.sh         # 一键配置脚本
├── README.md                     # 原始文档
├── README_PACKAGE.md             # 分发包说明
├── HZMI_RMSIMULATION_CONFIG_GUIDE.md  # 详细配置指南
└── QUICK_START.md                # 快速开始
```

### 步骤 2：排除不需要的文件

**不要包含以下文件夹：**
- ❌ `build/` - 编译产物
- ❌ `install/` - 安装文件
- ❌ `log/` - 日志文件
- ❌ `.git/` - Git 版本控制（我们不用 Git 传播）
- ❌ `.vscode/` - IDE 配置（可选）

### 步骤 3：创建压缩包

```bash
# 方法 1: 使用 tar
cd ~
tar -czvf HzMi_rmsimulation_config.tar.gz \
    --exclude='HzMi_rmsimulation/build' \
    --exclude='HzMi_rmsimulation/install' \
    --exclude='HzMi_rmsimulation/log' \
    HzMi_rmsimulation

# 方法 2: 使用 zip
cd ~/HzMi_rmsimulation
zip -r ../HzMi_rmsimulation_config.zip . \
    -x "build/*" \
    -x "install/*" \
    -x "log/*" \
    -x ".git/*"
```

## 📥 接收方如何使用

### 第一步：解压压缩包

```bash
# 对于 tar.gz 格式
cd ~
tar -xzvf HzMi_rmsimulation_config.tar.gz

# 对于 zip 格式
cd ~
unzip HzMi_rmsimulation_config.zip
```

### 第二步：进入目录

```bash
cd ~/HzMi_rmsimulation
```

### 第三步：运行一键配置脚本

```bash
chmod +x setup_from_package.sh
./setup_from_package.sh
```

这个脚本会自动完成：
1. ✅ 检查 ROS2 环境
2. ✅ 安装系统依赖
3. ✅ 安装 Livox SDK2（如果需要）
4. ✅ 安装 ROS 依赖
5. ✅ 编译工作空间
6. ✅ 设置脚本权限

### 第四步：启动仿真

```bash
source install/setup.bash
./start_sentinel.sh
```

## 📋 完整流程示例

### 发送方操作

```bash
# 1. 进入项目目录
cd ~/HzMi_rmsimulation

# 2. 运行打包脚本
./create_config_package.sh

# 3. 等待脚本完成
# 输出：HzMi_rmsimulation_config_package_20260319_143022.tar.gz

# 4. 发送压缩包给同学

```

### 接收方操作

```bash
# 1. 接收压缩包，保存到Downloads
cd ~/Downloads

# 2. 移动到家目录并解压
mv HzMi_rmsimulation_config_package_*.tar.gz ~
cd ~
tar -xzvf HzMi_rmsimulation_config_package_*.tar.gz

# 3. 进入项目目录
cd HzMi_rmsimulation

# 4. 运行配置脚本
chmod +x setup_from_package.sh
./setup_from_package.sh

# 5. 等待编译完成（可能需要几分钟）

# 6. 启动仿真
source install/setup.bash
./start_sentinel.sh
```

## 💡 最佳实践

### 1. 统一版本管理

每次更新代码后重新打包：

```bash
# 更新代码后
./create_config_package.sh

# 记录版本号
echo "v1.0.0 - 2026-03-19" > VERSION.txt

# 发送时注明版本
```

### 2. 提供清晰的说明

在发送压缩包时附带简要说明：

```
【HzMi_rmsimulation 配置包 v1.0.0】

包含内容：
- 完整的仿真和导航代码
- 自动配置脚本
- 详细使用文档

使用方法：
1. 解压到任意目录
2. 运行 ./setup_from_package.sh
3. 等待编译完成
4. source install/setup.bash
5. ./start_sentinel.sh

详细文档见压缩包内的 README_PACKAGE.md
```

### 3. 测试验证

在发送前，找一台干净的电脑测试：

```bash
# 在新环境中测试
docker run -it ubuntu:22.04 bash

# 安装 ROS2 Humble
# 解压配置包
# 运行 setup_from_package.sh
# 验证是否能正常启动
```

## ⚠️ 注意事项

### 1. 文件大小

完整的配置包大约 100-200MB，主要通过：
- 源码文件
- 3D 模型文件
- 地图文件

如果太大，可以考虑：
- 移除不必要的地图文件
- 压缩 3D 模型

### 2. 依赖问题

确保接收方：
- ✅ 已安装 Ubuntu 22.04
- ✅ 已安装 ROS2 Humble
- ✅ 有网络连接（下载依赖）

### 3. 权限问题

解压后确保脚本有执行权限：

```bash
chmod +x *.sh
```

`setup_from_package.sh` 会自动处理权限问题。

## 🆘 故障排除

### Q: 接收方编译失败
A: 检查是否已安装 ROS2 Humble，运行 `source /opt/ros/humble/setup.bash`

### Q: 缺少依赖
A: `setup_from_package.sh` 会自动安装，确保有网络连接

### Q: 文件损坏
A: 重新发送压缩包，或使用校验和验证：

```bash
# 发送方
md5sum HzMi_rmsimulation_config_package_*.tar.gz

# 接收方对比 MD5 值
```

| 特性 | Git/Gitee | 压缩包分发 |
